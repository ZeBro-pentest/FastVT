# SPEC — генератор видео-таймера (рабочее имя: video-timer)

Статус: **черновик v0.1**, этап 1 из 5 по SDD.
Имя проекта — `FastVT` (решено 29.09.2026, см. раздел 11), в документе используется `video_timer`.

## 0. Как читать документ

- `FR-xx` — функциональное требование, `NFR-xx` — нефункциональное.
- Приоритет: **M** (must, без него релиза нет), **S** (should), **C** (could).
- Каждое требование проверяемо: у него есть критерий приёмки в разделе 9.
- Код пишется только по этому документу. Нужна новая фича — сначала правка SPEC.

## 1. Цель

Программа накладывает секундомер или обратный отсчёт на видео, картинку или
однотонный фон и сохраняет готовый ролик. Ключевое свойство: рендер идёт на
скорости кодека (ffmpeg), а не в реальном времени. Пользователь запускает
программу кликом по файлу, без терминала и без установки Python.

## 2. Границы

**Входит:** движок рендера, CLI, Tkinter GUI, portable-сборка под Windows / macOS / Linux.

**Не входит (пока):** веб-версия, хостинг через ngrok/zrok, Docker как основной способ
доставки, автосборка релизов (CI), мобильные платформы (Termux — только CLI, без гарантий),
инсталляторы (Inno Setup, dmg).

## 3. Глоссарий

| Термин | Значение |
|---|---|
| Фон | видеофайл, картинка или сплошной цвет, поверх которого рисуется таймер |
| Режим | `stopwatch` (0 → вверх) или `countdown` (N → 0) |
| Hold | фаза после обнуления countdown: `00:00` горит заданным цветом N секунд |
| Fit | способ вписать фон в заданное разрешение: `stretch` / `contain` / `cover` |
| Job | один запуск рендера с полным набором параметров (`TimerConfig`) |

## 6. Архитектура


## 7. ТЗ по модулям (интерфейсы)

Ниже сигнатуры без реализации: это то, что уходит в каркас на этапе 3.

### 7.1 `config.py`

```python
class VideoTimerError(RuntimeError): ...

@dataclass
class TimerConfig:
    output: Path
    background: Path | None = None
    bg_color: str = "black"
    mode: Literal["stopwatch", "countdown"] = "stopwatch"
    countdown_seconds: float = 60.0
    duration: float | None = None
    fmt: Literal["mmss", "hhmmss", "mmssms"] = "mmss"
    position: Literal["tl", "tr", "bl", "br", "center"] = "br"
    font: Path | None = None
    font_size: int = 64
    color: str = "white"
    hold_seconds: float = 5.0
    hold_color: str = "#e6362c"
    bg_style: Literal["none", "shadow", "box"] = "shadow"
    resolution: str | None = None
    fit: Literal["stretch", "contain", "cover"] = "contain"
    fps: int = 30
    encoder: str | None = None
    crf: int = 18
    preset: str = "medium"

    def validate(self) -> None: ...
    def resolved_encoder(self) -> str: ...
    def known_total_duration(self) -> float | None: ...
```

Правила `validate()`:

| Поле | Условие |
|---|---|
| `countdown_seconds` | > 0 при mode=countdown |
| `hold_seconds` | ≥ 0 |
| `font_size` | 8…500 |
| `resolution` | `^\d+x\d+$`, обе стороны > 0 |
| `font` | файл существует, расширение .ttf/.otf/.ttc |
| `color`, `hold_color` | `#rgb`, `#rrggbb` или имя из белого списка |
| `crf` | 0…51 при libx264 |
| `fps` | 1…120 |
| `duration` | > 0, если задан; обязателен для stopwatch без видео-фона |
| `output` | расширение из FR-20 |
| `encoder` | совместим с контейнером (FR-21) |

### 7.2 `background.py`

```python
class Background:
    def __init__(self, cfg: TimerConfig) -> None: ...
    kind: Literal["video", "image", "color"]          # property
    def probe_duration(self) -> float | None: ...     # ffprobe; None если неизвестно
    def has_audio(self) -> bool: ...
    def input_args(self) -> list[str]: ...            # -i / -loop / -f lavfi
```

### 7.3 `filters.py`

```python
class FilterBuilder:
    def __init__(self, cfg: TimerConfig, background: Background) -> None: ...
    def build_scale_filter(self) -> str | None: ...   # FR-13, FR-14
    def build_timer_filters(self) -> list[str]: ...   # FR-01..FR-07
    def build(self) -> list[str]: ...
```

Инвариант: значение `text=` и значение `enable=` экранируются по-разному,
потому что `text=` разбирается дважды — парсером `-filter_complex`, а затем
самим `drawtext`. Проверено на ffmpeg 7.1:

| символ | где | замена |
|---|---|---|
| `:` | `text=` | `\\:` — два обратных слэша |
| `,` | `text=` | `\,` — один обратный слэш |
| `\` | `text=` | `\\` — два обратных слэша |
| `,` | `enable=` | `\,` — один обратный слэш |

Один слэш перед двоеточием в `text=` ffmpeg не разбирает («No option name near»),
три — рисуют лишний символ. Символ экранируется ровно один раз: повторный вызов
на уже экранированной строке даёт лишние слэши. Проверяется сравнением кадра с
`drawtext`, отрендеренным из `textfile`, — тот читает символы как есть.

### 7.4 `encoders.py`

```python
OUTPUT_CODECS: dict[str, dict[str, str]]              # ".mp4" → {video, audio}
def available_encoders() -> set[str]: ...             # ffmpeg -encoders
def pick_encoder(output: Path, requested: str | None) -> str: ...
```

Ограничение: проверка подтверждает, что кодек есть в сборке ffmpeg, но не что есть
железо (например, NVIDIA для `h264_nvenc`).

### 7.5 `estimate.py`

```python
@dataclass
class RenderEstimate:
    duration_seconds: float
    estimated_size_mb: float
    estimated_render_seconds: float
    note: str

def estimate(cfg: TimerConfig, background: Background) -> RenderEstimate: ...
```

Оценка — эвристика порядка величины (разрешение × CRF × длительность; скорость
кодека CPU/GPU). Точность не обещается.

### 7.6 `renderer.py`

```python
@dataclass
class RenderResult:
    output: Path
    duration_seconds: float | None
    tail_log: str

class RenderCancelled(VideoTimerError): ...

class FFmpegRenderer:
    def __init__(self, cfg: TimerConfig) -> None: ...
    def build_command(self) -> list[str]: ...
    def run(self, on_progress: Callable[[float, float | None], None] | None = None) -> RenderResult: ...
    def cancel(self) -> None: ...                     # FR-51

def render(cfg: TimerConfig, on_progress=None) -> RenderResult: ...   # validate + run
```

`run()` добавляет к команде `-progress pipe:2 -nostats` и читает поток
построчно: из `out_time_us` считается доля, из `progress=end` — завершение.
Поле называется `out_time_ms`, но ffmpeg пишет в нём микросекунды, поэтому
деление на миллион, а не на тысячу. Общая длительность берётся из
`TimerConfig.known_total_duration()`; для видео-фона без `duration` она равна
`None`, и GUI показывает неопределённый индикатор.

Папку результата создаёт `run()`, а не `validate()`: проверка конфигурации
работает без побочных эффектов, иначе отказ по любой другой причине оставил
бы на диске пустой каталог. `mkdir(parents=True, exist_ok=True)` идемпотентен —
GUI рендерит в один и тот же каталог для всех роликов. Если путь занят
файлом или нет прав на запись, пользователь получает
`output: не удалось создать папку <путь>: <причина>` (FR-41).

В сообщение об ошибке попадают последние 5 строк лога, а не весь хвост: причина
ошибки всегда в конце вывода, а до неё лежит баннер сборки — перечень кодеков
и версий библиотек на несколько тысяч символов. Полный хвост остаётся в
`RenderResult.tail_log` (FR-42, NFR-04).

## 9. Критерии приёмки

| # | Сценарий | Ожидаемо |
|---|---|---|
| A1 | countdown 10 с, hold 5 с, чёрный фон | ролик 15 с; на 9-й секунде `00:01`; с 10-й по 15-ю красный `00:00`; после — текста нет |
| A2 | stopwatch 8 с на чёрном фоне, `чч:мм:сс` | на 5-й секунде `00:00:05` |
| A3 | видео 16:9, `--resolution 1080x1080 --fit contain` | выход 1080×1080, чёрные поля сверху и снизу |
| A4 | то же, `--fit cover` | выход 1080×1080 без полей, края обрезаны |
| A5 | вывод в `.webm` | файл проигрывается, кодек vp9 |
| A6 | `.webm` + `--encoder libx264` | ошибка `encoder: …`, ffmpeg не запускался |
| A7 | `font-size 0` | ошибка `font-size: …`; в GUI подсвечено поле размера |
| A8 | `--estimate-only` для 3-часового ролика | ответ мгновенный, без запуска кодирования |
| A9 | рендер длинного видео в GUI | окно отзывается, прогресс растёт, отмена останавливает ffmpeg |
| A10 | запуск GUI без системного ffmpeg, но с `ffmpeg/` рядом | рендер работает |
| A11 | запуск GUI без ffmpeg вообще | окно открывается, показывает инструкцию, кнопка «Рендерить» объясняет причину |
| A12 | клик по `Запустить.bat` / `.app` / `.desktop` из произвольной папки | окно открывается без консоли |
