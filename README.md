---

> **FastVT** — это бесплатный видео-таймер с интерфейсом на Tkinter. Вы задаёте длительность
> и оформление, программа рендерит готовый видеофайл на вашей видеокарте или процессоре —
> без единого рекламного кадра и без лишних мегабайт.

## ✨ Возможности

| 🎞️ Рендеринг                                                        | 📉 Малый размер                            | 🎨 Кастомизация                                        |
| -------------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------ |
| GPU-ускорение (NVIDIA / Intel / AMD) с автоматическим откатом на CPU | Настраиваемый битрейт и минимум метаданных | Шрифт, размер, цвет, обводка, тень, позиция и анимации |

| 💾 Пресеты                                           | 📐 Адаптивность                           | 🪟 Простой UI                           |
| ---------------------------------------------------- | ----------------------------------------- | --------------------------------------- |
| Сохранение параметров и повторный рендер в один клик | Настройка разрешения и соотношения сторон | Всё необходимое в одном окне на Tkinter |

## 🚀 Установка

<details open>
<summary><b>🪟 Windows</b></summary>

1. Скачайте архив последнего релиза: [**Releases**](https://github.com/ZeBro-pentest/FastVT/releases/latest)
2. Распакуйте его в любую папку
3. Запустите `FastVT.exe`

> Антивирус может ругаться на неподписанную сборку — это нормально для новых сборок без сертификата. При необходимости добавьте файл в исключения.

</details>

<details>
<summary><b>🍎 macOS</b></summary>

1. Скачайте архив: [**Releases**](https://github.com/ZeBro-pentest/FastVT/releases/latest)
2. Распакуйте и переместите `FastVT.app` в «Программы»
3. При первом запуске: **правый клик → Открыть** (обход проверки Gatekeeper)

</details>

<details>
<summary><b>🐧 Linux</b></summary>

1. Скачайте архив: [**Releases**](https://github.com/ZeBro-pentest/FastVT/releases/latest)
2. Распакуйте и запустите:

```bash
chmod +x FastVT
./FastVT
```

Нужен Python 3 и Tkinter:

```bash
sudo apt install python3 python3-tk ffmpeg
```
</details>

<details>
<summary><b>🐍 Из исходников</b></summary>

```bash
git clone https://github.com/ZeBro-pentest/FastVT.git
cd FastVT
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
</details>

## 🎬 Как пользоваться

1. **Задайте длительность** таймера
2. **Настройте оформление** — шрифт, цвет, обводку, позицию, анимацию
3. **Выберите фон** — своё изображение, видео или однотонную заливку
4. **Настройте экспорт** — разрешение, кодек, частоту кадров
5. **Нажмите «Рендерить»** и дождитесь готовности
6. **Откройте результат** кнопкой в приложении

Все параметры сохранятся автоматически — в следующий раз повторный рендер займёт один клик.

## ❓ Вопросы и ответы

Нужен ли интернет для работы?

- Нет. Приложение полностью работает офлайн.

Будет ли работать на слабом ПК без видеокарты?

- Да. Рендер выполняется на процессоре, просто занимает больше времени.
