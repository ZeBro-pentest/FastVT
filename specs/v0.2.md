## 4. Детали требований

### 4.1 Фон и размер (FR-10, 12, 13, 14, 15)

- Картинка: длительность берётся из `duration`. Для countdown без `duration` итог = `countdown_seconds + hold_seconds`.
- Видео: длительность из файла, `duration` может только обрезать.
- `resolution` не задан → размер источника. Для цвета без `resolution` → 1920x1080.
- Звук (FR-15): копируется/перекодируется из видео-фона. У картинки и цвета звука нет, дорожка не создаётся.

### 4.2 Вывод (FR-20…23)

| Расширение | Видео | Аудио |
|---|---|---|
| `.mp4` | libx264 | aac |
| `.mov` | libx264 | aac |
| `.mkv` | libx264 | aac |
| `.webm` | libvpx-vp9 | libopus |

- `crf` и `preset` применяются только к libx264. Для других кодеков игнорируются без ошибки.
- Проверка по `ffmpeg -encoders` подтверждает, что кодек есть в сборке, но не что есть железо (см. `SPEC.md`, 7.4).

### 4.3 Оценка (FR-30, 31)

- `estimate()` не запускает кодирование: считает по разрешению, `fps`, `crf`, длительности и типу кодека.
- Возвращает `duration_seconds`, `estimated_size_mb`, `estimated_render_seconds`, `note`.
- Точность не обещается, везде подпись «приблизительно».
- В GUI блок оценки пересчитывается при смене любого параметра, который на неё влияет.

### 4.4 Отмена (FR-51)

- Кнопка «Отмена» вызывает `renderer.cancel()`: `terminate()`, при отказе через `_STOP_TIMEOUT_SECONDS` → `kill()`.
- Поднимается `RenderCancelled`, GUI показывает «Рендер отменён», не ошибку.
- Недописанный файл **удаляется** (предложенное решение, закрывает вопрос 4 из `SPEC.md`, см. раздел 7).

### 4.5 GUI (FR-52, 53, 54)

- Раскладка как в разделе 8 `SPEC.md`: тулбар, левая колонка параметров секциями, холст, журнал справа, снизу блок оценки + «Рендерить» / «Отмена» + прогресс-бар.
- Тема: `ttkbootstrap` если установлен, иначе `ttk`; отсутствие пакета не ошибка.
- «Открыть папку» активна только после успешного рендера.
- Пресеты в тулбаре пока не показываем (v0.3).

## 5. Нефункциональные требования версии

Действуют все NFR из `SPEC.md`. Для v0.2 особенно:

## 6. Критерии приёмки

Приёмка v0.2 = A3, A4, A5, A6, A8, A9 из `SPEC.md` (раздел 9) + регрессия A1, A2, A7, A11 из v0.1.

| # | Сценарий | Ожидаемо |
|---|---|---|
| A3 | видео 16:9, `--resolution 1080x1080 --fit contain` | выход 1080×1080, чёрные поля сверху и снизу |
| A4 | то же, `--fit cover` | выход 1080×1080 без полей, края обрезаны |
| A5 | вывод в `.webm` | файл проигрывается, кодек vp9 |
| A6 | `.webm` + `--encoder libx264` | ошибка `encoder: …`, ffmpeg не запускался |
| A8 | `--estimate-only` для 3-часового ролика | ответ мгновенный, кодирование не запускается |
| A9 | рендер длинного видео в GUI | окно отзывается, прогресс растёт, отмена останавливает ffmpeg |

Регрессия: A1, A2, A7, A11 остаются зелёными.

Конец версии: приёмка по критериям, тег `v0.2`, обновлённая спека, запись в `CHANGELOG.md`.
