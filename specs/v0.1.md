# Спека v0.1 «Старт»

Срок: **28.09 → 07.10.2026**. Источник требований: `SPEC.md`. План по дням: `ROADMAP.md`.
Статус: скоуп заморожен 28.09.

## Цель версии

Минимальная рабочая программа: окно с несколькими полями и кнопка «Рендерить».
Всё, чего нет в этом файле, в v0.1 не делается.

## Требования версии

| ID | Требование в рамках v0.1 | Пр. |
|---|---|---|
| FR-01 | Секундомер: значение = время от начала ролика | M |
| FR-02 | Обратный отсчёт: значение = N − t, N в секундах | M |
| FR-03 | После обнуления `00:00` красным 5 секунд, затем текст исчезает (`hold_seconds` по умолчанию 5) | M |
| FR-04 | Формат часов только `мм:сс` | M |
| FR-05 | Позиция: 4 угла и центр | M |
| FR-06 | Размер шрифта 8–500 и цвет текста; шрифт системный по умолчанию | M |
| FR-10 | Фон: сплошной цвет (по умолчанию чёрный) или видеофайл | M |
| FR-11 | Для видео-фона длительность берётся из файла | M |
| FR-12 | Для цветного фона `duration` обязателен в режиме секундомера; в режиме отсчёта длительность = N + hold | M |
| FR-20 | Вывод только `.mp4` (libx264) | M |
| FR-40 | Все параметры проверяются до запуска ffmpeg методом `TimerConfig.validate()` | M |
| FR-41 | Ошибка вида `«поле: что не так»`, GUI подсвечивает поле; папка результата создаётся сама | M |
| FR-42 | Трейсбек и сырой лог ffmpeg пользователю не показываются | M |
| FR-50 | Базовый CLI: все параметры v0.1 | M |
| FR-51 | GUI: поля параметров, рендер в отдельном потоке, прогресс-бар (без отмены) | M |
| FR-55 | Если ffmpeg не найден, окно открывается и показывает понятное сообщение | M |

## Не входит в v0.1

Картинка как фон, своё разрешение и `fit`, форматы кроме mp4, выбор кодека, свои шрифты,
форматы часов кроме `мм:сс`, подложка, оценка размера и времени, отмена рендера,
журнал, раскладка по макету, пресеты, предпросмотр, portable-сборка.

## Параметры (`TimerConfig` в v0.1)

| Поле | Тип | По умолчанию | Проверка |
|---|---|---|---|
| `output` | Path | — | расширение `.mp4` |
| `background` | Path \| None | None | файл существует; расширение видео (`.mp4 .mov .mkv .webm .avi .m4v`) |
| `bg_color` | str | `black` | `#rgb`, `#rrggbb` или имя из белого списка |
| `mode` | `stopwatch` \| `countdown` | `stopwatch` | одно из двух |
| `countdown_seconds` | float | 60 | > 0 при countdown |
| `duration` | float \| None | None | > 0; обязателен для stopwatch без видео-фона |
| `position` | `tl tr bl br center` | `br` | одно из пяти |
| `font_size` | int | 64 | 8…500 |
| `color` | str | `white` | как `bg_color` |
| `hold_seconds` | float | 5 | ≥ 0 |
| `hold_color` | str | `#e6362c` | как `bg_color` |
| `fps` | int | 30 | 1…120 |

Формат часов зафиксирован: `мм:сс`. Кодек зафиксирован: libx264, CRF 18, preset medium.

## Интерфейсы v0.1

**CLI:**

```
python -m video_timer.cli -o out.mp4 --mode countdown --countdown-seconds 10 \
    [-b video.mp4] [--bg-color black] [--duration 30] [--position br] \
    [--font-size 64] [--color white] [--hold-seconds 5] [--hold-color "#e6362c"] [--fps 30]
```

Коды возврата: 0 — успех, 1 — ошибка валидации или рендера, 2 — неверные аргументы.

**GUI:** одно окно, поля из таблицы выше, кнопка «Рендерить», прогресс-бар, строка
статуса с ошибкой или путём к результату. Раскладка по макету в v0.2.
